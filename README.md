## 📁 机器学习

**复习资料**：[飞书文件夹](https://my.feishu.cn/drive/folder/WWtFfhM15lGdnLdkShocw0RGnJe)

**复习建议**：

1. 逃课？好，派总也逃课。贴心的派总为比奇堡居民们整理了以应试为目标的学习方案：刷题！刷题！还是tm的刷题！
2. 关于复习，派总是这么想的：
	（1）先从网上大量搜集历年考题，当然越是近些年的考题越好，越是咱自个儿老师出的题越好
	（2）将上课用的PPT和试题一股脑喂给GPT/Claude/Kimi，然后设定好提示词，确保：PPT管边界，试题管内容，让各个AI输出各自的考点汇总
	（3）将这些考点汇总做交叉，生成最终的汇总报告
	（4）依据最终的汇总报告，一个考点一个考点的过，概念、案例、题目都要详实学习
	（5）finally，查漏补缺，比如扩展一下考点的边界、做一下PPT课后题、网上搜寻一下其他题目等
3. OnGoing 阶段 ~
